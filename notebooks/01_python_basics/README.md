# Python 기초

Python 프로그래밍의 기초를 학습합니다.

## 학습 목표
- Python 기본 문법 이해
- 데이터 타입 및 자료구조 다루기
- 함수와 클래스 작성
- 파일 입출력

## 학습 내용

### 1. 기본 문법
- 변수 및 데이터 타입
- 연산자
- 조건문 (if-elif-else)
- 반복문 (for, while)

### 2. 자료구조
- 리스트 (List)
- 튜플 (Tuple)
- 딕셔너리 (Dictionary)
- 집합 (Set)

### 3. 함수
- 함수 정의 및 호출
- 매개변수와 반환값
- Lambda 함수
- 내장 함수

### 4. 객체지향 프로그래밍
- 클래스 정의
- 객체 생성
- 상속
- 메서드

## 실습 파일
- `01_basics.py` - 기본 문법
- `02_data_structures.py` - 자료구조
- `03_functions.py` - 함수
- `04_oop.py` - 객체지향

## 연습 문제
1. 리스트를 받아 평균을 계산하는 함수 작성
2. 딕셔너리로 학생 성적 관리 프로그램 작성
3. 간단한 계산기 클래스 구현
